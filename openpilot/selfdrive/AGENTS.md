# selfdrive/ - DRIVING STACK

Per-frame driving daemons. Stock openpilot core. SP extensions live in [openpilot/sunnypilot/selfdrive/](file:///Users/cyonsun/Documents/Code/sunnypilot/openpilot/sunnypilot/selfdrive). See parent [AGENTS.md](file:///Users/cyonsun/Documents/Code/sunnypilot/AGENTS.md) for global conventions.

## STRUCTURE

```
selfdrive/
├── car/             # card daemon - thin Python car interface (uses opendbc/car/)
├── controls/        # controlsd, plannerd, radard + lib/ (lat/long MPC, controllers)
├── selfdrived/      # State machine, alert mgmt, events
├── modeld/          # SNPE-based modeld + dmonitoringmodeld (PC fallback)
├── locationd/       # locationd, calibrationd, paramsd, torqued, lagd
├── pandad/          # C++ pandad - USB/SPI bridge to panda firmware
├── monitoring/      # Driver attention monitoring (dmonitoringd)
├── ui/              # Raylib UI - layouts, widgets, onroad, soundd, feedback
├── assets/          # Icons + offroad HTML + sounds
└── test/            # Cross-module integration: process_replay, longitudinal_maneuvers, cpp_harness
```

## DAEMON PIPELINE

```
panda(USB) -> pandad(C++) -> card -> [controlsd <- modeld -> plannerd] -> selfdrived -> ui
                                       ^                                       |
                                       +-- locationd <- camerad <- pandad      v
                                                                            soundd, feedbackd
```

Run a single daemon for testing (after `op_activate_venv`):
```bash
python -m openpilot.selfdrive.controls.controlsd
```

## ANTI-PATTERNS (THIS DIR)

- **NEVER edit `openpilot/selfdrive/modeld/models/generated/`** - regenerated by SCons via tinygrad compile.
- **NEVER edit `openpilot/selfdrive/locationd/models/generated/`** - regenerated by rednose.
- **NEVER bypass `card`** to read CAN directly in controlsd - always go through cereal `carState`.
- **NEVER touch `selfdrived/helpers.py` excessive actuation checks** - banned ([docs/SAFETY.md](file:///Users/cyonsun/Documents/Code/sunnypilot/docs/SAFETY.md#L39)).
- **NEVER touch `monitoring/`** to disable driver attention - banned.
- **DO NOT add UI features here** - prefer SP screens in [openpilot/selfdrive/ui/sunnypilot/](file:///Users/cyonsun/Documents/Code/sunnypilot/openpilot/selfdrive/ui/sunnypilot).
- **DO NOT use `pyray.is_mouse_button_pressed/released`** - use `Widget._handle_mouse_press/release` (lint-banned via TID251).
- **DO NOT reintroduce a vendored raylib include path** - raylib comes from the `comma-deps-raylib` wheel; C++ uses a bare `#include "raylib.h"`.
