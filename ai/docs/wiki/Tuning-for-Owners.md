# Tuning for Owners

面向**不懂参数名**的车主。

## 怎么说

| 你的感受 | 可以这样说 |
|----------|------------|
| 跟车太近/太远 | 「跟车距离不舒服，想远一点」 |
| 变道太猛 | 「变道太急，想柔和一点」 |
| 加速/刹车突兀 | 「加减速太冲」 |
| 高速画龙 | 「高速有点画龙」 |

## 推荐入口

1. Web 首屏 **「调驾驶手感」**  
2. `op tune` 或 `/调手感`  
3. 聊天里直接描述感受  

## 流程

1. AI 先读当前设置（你不需要懂参数名）  
2. 提议 **1–3 项最小改动**，用中文解释每项会带来什么感觉  
3. **确认卡** 显示改前/改后 → 你点确认  
4. 试开一段 → 不满意说「撤销上次调参」  

## 注意

- 需在**静止**时改设置  
- 重大改动前会自动保存快照（调参护照）  
- 可要求对比改参前后两条路线
