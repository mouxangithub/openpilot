## 2. 冲突处理规则（可复用）

| # | 规则 | 用法 |
|---|---|---|
| 1 | **三方 token 计数定归属** | `git show base/test/tn:<file> \| grep -c <token>`：base==tn ⇒ test 新增（保 test）；base==test ⇒ tn 改动（取 tn） |
| 2 | **UI 文件固定模式** | test 侧 = `tr()` i18n 包装；tn 侧 = 上游新特性（`description=`、CellularManager、精简文案）⇒ **取 tn 结构 + 用 `tr()` 包住用户可见字符串** |
| 3 | **超集优先** | 一侧是另一侧超集时取超集 |
| 4 | **顺带查依赖** | 取一侧后，检查另一侧的引用是否悬空（导入/调用/构建输入） |
